# 贡献指南

感谢你愿意为 GitPocket_75 提交代码或建议。为了让协作过程清晰，请在动手前花两分钟读完下面的约定。

## 提交 Issue

- 提交前先检索已有 Issue，避免重复。
- Bug 反馈请说明：运行环境（JDK 版本、操作系统）、复现步骤、期望结果与实际结果、控制台输出。
- 功能建议请说明使用场景：你希望在什么情况下用这个功能，解决什么问题。模板见 `.github/ISSUE_TEMPLATE/`。

## 提交代码

1. 从 `develop` 拉出分支，命名规则为 `feature/功能名` 或 `fix/问题名`，例如 `feature/quiz-random`、`fix/search-empty-input`。
2. 代码保持 JDK 11 兼容，不引入第三方依赖。
3. 类名使用大驼峰，方法与变量使用小驼峰，常量全大写加下划线。
4. 提交信息采用 `类型: 描述` 格式，类型为 feat、fix、docs、refactor 之一，例如 `feat: 练习题库支持随机抽题`。
5. 推送分支后向 `develop` 发起 Pull Request，说明改动内容与验证方式，等待至少一位同学 Review 后合并。

## 代码风格

- 单个方法不超过 40 行，超过时拆分为私有方法。
- 面向用户的输出一律使用中文，标点使用全角。
- 不吞异常：捕获 `IOException` 时必须给出提示或降级处理。
